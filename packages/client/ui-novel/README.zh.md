# @deepseek-ai/dsh-client-ui-novel

[English](README.md) | 中文

网页应用的**小说工作区**与**酒馆**表面:一个设置标签页,外加两个全屏项目面板,各自由一枚可拖动的悬浮印章打开。浏览器插件注册一个本地化 `settings.plugins.tab` 贡献(id `novel`)和四个 `shell.overlay` 贡献——小说工作室的悬浮印章与全屏浏览器(`novel-seal`、`novel-studio`)以及酒馆的悬浮印章与全屏浏览器(`tavern-seal`、`tavern-studio`)。每枚印章与自己的面板共享同一个 store 句柄,开关状态与屏幕位置永远不会在两个表面之间分歧;两个面板之间绝不共享 store。插件激活时不发起任何 Remote 读取:选中标签页或打开某个面板时才挂载,并通过 [`api-remotes`](../../api/remotes/README.md) 惰性加载。

小说工作室用一份快照渲染整个小说工作区:世界折叠点与带类型徽标和折叠字段的主体卡片、按故事顺序排列的时间线、带状态徽章与演进历史的伏笔台账、带选项与结局的创作决策、章节知识控制行、正文草稿与 canon 设定库。展示形式的故事时间与存储根目录原样展示。加载、失败、空态与重试状态都留在已挂载的组件内部;「重新读取」按钮按需重新拉取快照。当部署未挂载 novel 服务时,读取会大声失败,这些表面展示带说明的未启用状态,而不是传输细节。

酒馆表面默认是微信式聊天应用:左侧是会话列表(每个酒馆绑定的会话显示绑定角色卡的 PNG 人设图作为头像,悬停可删除/归档对话),右侧是气泡对话。「开始新对话」会自动创建一个使用 `tavern` 预设的新会话、绑定角色卡与世界书并直接打开对话,角色会先开口打招呼;消息通过 `session.prompt` 发送,并通过轮询 `session.history` 获取回复。「资料库」标签保留管理界面:世界书及其条目、带人设图与扩展字段的角色卡、导入(角色卡 PNG 含 `chara`/`ccv3` 数据块,或 JSON;世界书 JSON 导出)、删除,以及会话绑定控制(开始/停止/解除扮演)。删除对话通过 `workspace.archiveSession` 归档会话,它会从所有列表消失,而数据仍可在存储中找回。常见导入失败会映射为可操作的说明(例如 PNG 缺少卡片元数据)。注册使用 `ctx.slots.inject()`,因此能跟随迟到声明、重新声明、语言切换与卸载,而无需导入槽所有者。

## Model Experience

无——本包只在浏览器里可视化 Host 持有的快照并驱动酒馆 RPC 域,不注册任何面向模型的内容。

#### KV Cache effect

无;本包既不组装也不发送 provider 请求。

## Known Limitations and Deferred Work

- **每次设置挂载或面板打开只有一份快照** —— 这些表面不订阅存储变更,也不在重连后自动重拉;切换标签页或收起面板保留当前快照,重新打开设置、关闭再打开面板或点击刷新才会拿到新快照。酒馆面板里的导入与删除会按需重载项目树。
- **酒馆管理仅限浏览器** —— 变更(导入、删除、绑定)都经由酒馆 RPC 域完成;小说工作区在此处保持只读,写入仍然经由 novel 工具与服务完成。
